# fieldnote CLI — Slice B: `fieldnote run`

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `fieldnote run` grade the repository you are standing in and print the result with its evidence, so the CLI is worth installing.

**Architecture:** The CLI resolves the repository slug and commit from git locally, refuses if the commit is not pushed, then `POST`s to `/api/cli/grades` and polls one endpoint until the row lands. The server reuses `requestGrade()` and `dispatchGrade()` unchanged — the same two calls the web app's `runGrade` action makes — so there is one path to a grade and no second implementation to drift. Rendering is a pure function from `GradeResult` to lines.

**Tech Stack:** TypeScript 6, Node 24+, pnpm workspaces, Next.js 16 route handlers, Drizzle ORM + Postgres, Inngest, Zod 4, Vitest 4.

**Spec:** [`docs/superpowers/specs/2026-09-13-cli-design.md`](../specs/2026-09-13-cli-design.md)

**Predecessor:** [`docs/superpowers/plans/2026-09-13-cli-sign-in.md`](2026-09-13-cli-sign-in.md) (slice A, merged). Its execution surfaced two blocking prerequisites, which are Tasks 2 and 3 here.

## Global Constraints

- **Node 24+.** Relative imports inside `packages/cli/src/` carry explicit `.ts` extensions — the package has no build step and Node's ESM resolver will not resolve extensionless specifiers. `allowImportingTsExtensions` is set on the root tsconfig and `packages/cli/tsconfig.json`.
- **Formatting:** `pnpm prettier --write <the files you changed>`. Never bare `pnpm format` — it reformats all of `src/`, which other branches edit. Stage only your own files; never `git add -A`.
- Prettier: `singleQuote: true`, `trailingComma: "all"`, `printWidth: 100`.
- **Verification:** `pnpm lint && pnpm typecheck && pnpm test` must pass at every commit, with **0 warnings**. `pnpm test:integration` requires a `_test` database; run it where one exists.
- **`render.ts` is the only module that knows about `isTTY`, colour, `CI` or `NO_COLOR`.** Nothing else may check them.
- **`run()` in `bin.ts` returns an exit code and never calls `process.exit`.**
- **Exit codes:** `0` success · `1` graded, below threshold · `2` could not grade · `3` not signed in.
- **Never store or log a plaintext token.** Use `tokenHash()` from `src/auth/crypto.ts`.
- **Ubiquitous language:** bare "check" is forbidden. A **grader check** is one criterion in a grader's rubric; a **CI check** is a GitHub check run. Say which.
- **Attribution:** end every commit message with
  `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>`

## What this slice must not do

- **No local grading.** The engine stays server-side; that decision is settled in the spec. If it ever changes it arrives as `fieldnote run --local`.
- **No registry.** `publish` / `add` / `update` stay unbuilt and unlisted.
- **No MCP.** `fieldnote mcp` remains the placeholder it is.
- **No `--push`.** The spec records this as an open question. `run` refuses clearly on unpushed work and tells the developer what to run; it does not write to anyone's remote.

### Task 2: `requireWorkspace()` fails closed on a pinned workspace

**Files:**
- Modify: `src/workspaces/access.ts`
- Test: `src/workspaces/access.integration.test.ts`

**Interfaces:**
- Consumes: `currentPrincipal()` from `src/auth/principal.ts`.
- Produces: no new exports. Behaviour change only.

**Why:** a CLI token's `workspace_id` is pinned at issue precisely so its blast radius cannot change. Today, if that workspace matches no membership — revoked access, a workspace deleted, a misissued token — `requireWorkspace()` silently falls back to the user's default workspace. The token then operates somewhere the user never authorised. This must fail closed **before** any route hands a principal to it, which is Task 3.

      requireWorkspace(),
    ),
  ).rejects.toThrow();
});

it('still honours a principal naming a workspace the user IS in', async () => {
  const workspace = await withPrincipal(
    { userId, workspaceId, source: 'cli' },
    () => requireWorkspace(),

- [ ] **Step 3: Make a pinned workspace bind the way an explicit argument does**

In `src/workspaces/access.ts`, replace the `preferred`/`membership` logic:

```ts

  const explicit = workspaceId !== undefined;
  // A principal's workspace is pinned at issue, so it binds exactly the way an
  // explicit argument does: naming a workspace this user is not in fails closed
  // rather than quietly falling back to their default. A cookie preference may
  // fall back — it is a convenience. A token's workspace is a boundary.
  const pinnedId = explicit ? workspaceId : principal?.workspaceId;
  const bound = pinnedId !== undefined;
  const preferred = bound ? pinnedId : (await cookies()).get(workspaceCookie)?.value;

and further down:

```ts
  const membership = bound

    : preferred
      ? memberships.find(({ id }) => id === preferred)
      : fallback;
  if (!membership && bound) notFound();
```

When there is no principal and no explicit argument, `bound === explicit`, so every pre-existing path is unchanged character-for-character.

```ts
import { isRedirectError } from 'next/dist/client/components/redirect-error';
import { unstable_rethrow } from 'next/navigation';
import { resolveToken } from '../../../db/queries/cli-tokens';
import { withPrincipal } from '../../../auth/principal';

const headers = { 'Cache-Control': 'private, no-store' };
const unauthorized = () => Response.json({ error: 'Not signed in.' }, { status: 401, headers });

// Every CLI route goes through this door, so authentication, scope and the
// redirect-to-401 conversion exist once rather than per route.
//
// The redirect conversion is the subtle one. sessionUser() redirects when the
// user row is gone, and an uncaught redirect throw becomes a 307 — which a CLI
// HTTP client follows, landing it in a sign-in page's HTML instead of an error
// it can act on.
export async function withCliPrincipal(
  request: Request,
  scope: 'grade',
  handler: () => Promise<Response>,
): Promise<Response> {
  const token = request.headers.get('authorization')?.replace(/^Bearer\s+/i, '');
  if (!token) return unauthorized();

  const principal = await resolveToken(token);
  // A revoked token and one that never existed are indistinguishable here on
  // purpose: an unauthenticated caller learns nothing about which it was.
  if ('error' in principal) return unauthorized();

  if (principal.scope !== scope)
    return Response.json(
      { error: `This token cannot ${scope}. Run \`fieldnote login\` again.` },
      { status: 403, headers },
    );

  try {
    return await withPrincipal(
      { userId: principal.userId, workspaceId: principal.workspaceId, source: 'cli' },
      handler,
    );
  } catch (error) {
    if (isRedirectError(error)) return unauthorized();
    unstable_rethrow(error);
    return Response.json(
      { error: 'fieldnote is temporarily unavailable. Try again.' },
      { status: 503, headers },
    );
  }
}
```

If `isRedirectError` is not importable from that path in this Next version, detect it by the digest instead: a redirect error has a `digest` string beginning `NEXT_REDIRECT`. Do not let `unstable_rethrow` see it first — it rethrows redirects by design, which is exactly what this function exists to prevent.

### Task 4: `POST /api/cli/grades`

**Files:**
- Create: `src/app/api/cli/grades/route.ts`
- Test: `src/app/api/cli/grades/route.test.ts`

**Interfaces:**
- Consumes: `withCliPrincipal` (Task 3); `requestGrade(repositoryId, graderId)` and `dispatchGrade(runId)`; `accessibleRepositories()` from `src/workspaces/access.ts`; `AGENT_READINESS` from `src/domain/grading/graders/agent-readiness`.
- Produces: `POST /api/cli/grades` accepting `{ repository, sha, grader? }`, returning `{ runId, graderId, mode, requestedSha }`.

**Why `requestedSha` and not `sha`.** `requestGrade()` neither accepts nor stores a sha — `grade_runs.sha` is pinned later by the collection worker, from the repository's **default branch head**. A developer standing on a pushed feature branch would otherwise get their own sha handed straight back while the server graded `main`: a lie printed in a terminal. The request body still carries `sha`, because it is the CLI's honest claim about where it stands and the poll discloses any mismatch against it.

**Design note — the CLI sends a slug, not an id.** The CLI knows `dervalp/fieldnote` from the git remote; it has no idea what a fieldnote `repositoryId` is, and it should not. The route resolves the slug against the repositories this workspace can actually see, which makes an unknown repository and an unauthorised one indistinguishable to the caller — the right default.

```ts
import { z } from 'zod';
import { withCliPrincipal } from '../principal';
import { accessibleRepositories } from '../../../../workspaces/access';
import { requestGrade } from '../../../../db/queries/grade-runs';
import { dispatchGrade } from '../../../../inngest/dispatch-grade';
import { getGrader } from '../../../../domain/grading/registry';
import { AGENT_READINESS } from '../../../../domain/grading/graders/agent-readiness';

const headers = { 'Cache-Control': 'private, no-store' };

const bodySchema = z.object({
  repository: z.string().regex(/^[^/\s]+\/[^/\s]+$/),
  sha: z.string().regex(/^[0-9a-f]{40}$/),
  grader: z.string().optional(),
});

export async function POST(request: Request) {
  return withCliPrincipal(request, 'grade', async () => {
    const body = bodySchema.safeParse(await request.json().catch(() => null));
    if (!body.success)
      return Response.json(
        { error: 'Send a repository as owner/name, and a full 40-character sha.' },
        { status: 400, headers },
      );

    const [owner, name] = body.data.repository.split('/');
    // Resolved against what this workspace can see, so an unknown repository
    // and an unauthorised one are the same answer.
    const repositories = await accessibleRepositories();
    const repository = repositories.find((r) => r.owner === owner && r.name === name);
    if (!repository)
      return Response.json(
        { error: `fieldnote is not connected to ${body.data.repository}.` },
        { status: 404, headers },
      );

    const graderId = body.data.grader ?? AGENT_READINESS;
    const manifest = getGrader(graderId);

    // requestGrade checks workspace membership, repository connection and demo
    // mode, and holds the one-live-run-per-repository-and-grader constraint.
    const run = await requestGrade(repository.id, graderId);
    try {
      await dispatchGrade(run.id);
    } catch {
      // A queued run is recovered by reconciliation; keep its polling identity.
    }

    return Response.json(
      { runId: run.id, graderId, mode: manifest.mode, sha: body.data.sha },
      { headers },
    );
  });
}
```

Check `accessibleRepositories()`'s actual row shape before relying on `owner`/`name`; if the columns are named differently, match them and say so in your report.

```ts
import { withCliPrincipal } from '../../principal';
import { loadGradeRun } from '../../../../../db/queries/grade-runs';
import { accessibleRepositories } from '../../../../../workspaces/access';
import { graderCheckTitles, getGrader } from '../../../../../domain/grading/registry';

const headers = { 'Cache-Control': 'private, no-store' };
const notFound = () => Response.json({ error: 'Grade unavailable.' }, { status: 404, headers });

export async function GET(request: Request, context: { params: Promise<{ runId: string }> }) {
  return withCliPrincipal(request, 'grade', async () => {
    const { runId } = await context.params;
    const run = await loadGradeRun(runId);
    if (!run) return notFound();

    // Re-check on every poll, not only at request time: access can be revoked
    // while a run is in flight, and a poll loop is the easiest place to miss it.
    const repositories = await accessibleRepositories();
    if (!repositories.some((r) => r.id === run.repositoryId)) return notFound();

    if (run.state !== 'complete' || !run.result)
      return Response.json({ state: run.state }, { headers });

    return Response.json(
      {
        state: run.state,
        score: run.result.score,
        checks: run.result.checks,
        titles: graderCheckTitles(run.graderId),
        tagline: getGrader(run.graderId).card.tagline,
        rubricVersion: run.result.rubricVersion,
        evaluatorVersion: run.result.evaluatorVersion,
      },
      { headers },
    );
  });
}

```ts
import { execFile } from 'node:child_process';
import { promisify } from 'node:util';

const run = promisify(execFile);

export type GitState = {
  slug: string | null;
  sha: string | null;
  dirtyCount: number;
  unpushedCount: number;
  hasUpstream: boolean;
};

// Accepts every remote form GitHub hands out — scp-style, https, ssh:// — and
// nothing else. A non-GitHub remote is not an error here; it is a repository
// fieldnote cannot grade, which the blocker reports in its own words.
export function parseSlug(remoteUrl: string): string | null {
  const match = remoteUrl
    .trim()
    .match(/^(?:git@github\.com:|(?:ssh:\/\/)?(?:git@)?(?:https?:\/\/)?github\.com\/)(.+?)(?:\.git)?$/);
  if (!match) return null;
  const slug = match[1];
  return /^[^/\s]+\/[^/\s]+$/.test(slug) ? slug : null;
}

async function git(cwd: string, args: string[]): Promise<string | null> {
  try {
    const { stdout } = await run('git', args, { cwd });
    return stdout.trim();
  } catch {
    return null;
  }
}

export async function readGitState(cwd: string): Promise<GitState> {
  const sha = await git(cwd, ['rev-parse', 'HEAD']);
  if (sha === null)
    return { slug: null, sha: null, dirtyCount: 0, unpushedCount: 0, hasUpstream: false };

  const remote = await git(cwd, ['remote', 'get-url', 'origin']);
  const status = await git(cwd, ['status', '--porcelain']);
  const upstream = await git(cwd, ['rev-parse', '--abbrev-ref', '@{u}']);
  const ahead = upstream === null ? null : await git(cwd, ['rev-list', '--count', '@{u}..HEAD']);

  return {
    slug: remote === null ? null : parseSlug(remote),
    sha,
    dirtyCount: status ? status.split('\n').filter(Boolean).length : 0,
    unpushedCount: ahead ? Number(ahead) : 0,
    hasUpstream: upstream !== null,
  };
}

// An error that ends in a command the reader can run is a fix. One that ends in
// a rule is homework.
export function gradeBlocker(
  state: GitState,
): { reason: 'not-a-repo' | 'no-remote' | 'dirty' | 'unpushed'; lines: string[] } | null {
  if (state.sha === null)
    return { reason: 'not-a-repo', lines: ['  This is not a git repository.'] };

  if (state.slug === null)
    return {
      reason: 'no-remote',
      lines: [
        '  This repository has no GitHub remote named origin.',
        '',
        '  fieldnote grades what it can fetch from GitHub.',
      ],
    };

  if (state.dirtyCount > 0 || state.unpushedCount > 0) {
    const counts = [
      state.dirtyCount > 0 ? `${state.dirtyCount} file${state.dirtyCount === 1 ? '' : 's'} changed` : null,
      state.unpushedCount > 0
        ? `${state.unpushedCount} commit${state.unpushedCount === 1 ? '' : 's'} not pushed`
        : null,
    ].filter(Boolean);

    return {
      reason: state.unpushedCount > 0 ? 'unpushed' : 'dirty',
      lines: [
        '  There is nothing here fieldnote can read yet.',
        '',
        `     ${counts.join(', ')}`,
        '',
        '     fieldnote grades a commit its server can fetch from GitHub.',
        '     Your working tree is not one.',
        '',
        '  WHAT YOU PROBABLY WANT',
        '',
        '    push this branch, then grade its head',
        '      git push && fieldnote run',
        '',
        '    grade a commit that is already pushed',
        `      fieldnote run --sha ${state.sha.slice(0, 7)}`,
        '',
        '    see what has not been graded',
        '      git status --short',
      ],
    };
  }

  return null;
}
```

Note the last test: the copy names counts, never the word "dirty". That is deliberate — a count is checkable, an adjective is a state the developer has to go and confirm.

**Interfaces:**
- Consumes: `GradeComplete` and `GradeCheck` from `./api.ts` — type-only imports, same package.
- Produces: `gradeLines(input: GradeView): Line[]`, plus the `Line` and `GradeView` types below.

**Why a Line union rather than strings:** `render.ts` owns colour. `grade-view.ts` says what each line *means*; `render.ts` decides what that looks like. Keeping them apart is what let slice A test the banner's degradation table without a terminal.

**The import boundary, resolved.** The CLI **cannot** import `src/domain/grading/`, for two reasons that are worth stating because both are invisible to the test suite:

1. `packages/cli` is a publishable npm package with its own `package.json` and zero dependencies. A `../../../src/domain/...` specifier reaches outside the package and breaks the published tarball.
2. Those modules use extensionless relative specifiers — `next-tier.ts` imports `'./presentation'`. The CLI has no build step; its only runtime is Node's ESM resolver, which cannot resolve those. Vitest and `tsc` both use bundler resolution and would never see the failure. This is slice A's `ERR_MODULE_NOT_FOUND` bug one layer out.

**So the grading judgement stays on the server**, where it already lives: the poll response carries `presentation`, `nextTier`, `disclaimer` and `tagline` precomputed, and Task 8 has already typed all of it as `GradeComplete`. `grade-view.ts` derives its input from that type rather than restating it, formats what it is told, and decides nothing about grading.

**Two shapes this module must handle honestly, both of which the server can really produce:**

- **`score` is `null`** — evidence collection was incomplete. That is not a zero, and `presentation` is `null` alongside it. Print the reason, never a `0`.
- **`gradedSha` differs from the sha the CLI sent, or is `null`.** The server grades the repository's **default branch head**, not the commit in the working tree. `POST` echoed the caller's sha back as `requestedSha`; the poll returns `gradedSha`. When they differ, say so above the card — the grade is real, it is simply not about the commit the developer is standing on. This disclosure belongs here, not in `bin.ts`, because here it is a pure function of two strings and can be tested without a terminal.

```ts
import type { GradeCheck, GradeComplete } from './api.ts';

export type Line = {
  kind: 'card' | 'pass' | 'fail' | 'partial' | 'dim' | 'head' | 'blank' | 'url';
  text: string;
};

// Everything the server computed, plus the two things only the CLI knows:
// which repository the developer is standing in, and which commit they asked
// about. Derived from GradeComplete rather than restated, so the contract
// cannot drift from the client that fetches it.
export type GradeView = GradeComplete & { slug: string; requestedSha: string };

// A grader check's own `status` is binary, but its points are not: a rubric
// with partial credit returns `pass` for a check that earned 12 of 20. Reading
// the points rather than the status is what keeps "pass" meaning "all of it".
function kindOf(check: GradeCheck): 'pass' | 'fail' | 'partial' {
  if (check.points >= check.maxPoints) return 'pass';
  if (check.points <= 0) return 'fail';
  return 'partial';
}

const short = (sha: string) => sha.slice(0, 7);

export function gradeLines(input: GradeView): Line[] {
  const lines: Line[] = [];
  const title = (check: GradeCheck) => input.titles[check.id] ?? check.id;

  lines.push({
    kind: 'head',
    text: input.gradedSha
      ? `${input.slug} · ${short(input.gradedSha)}`
      : `${input.slug} · commit unknown`,
  });
  lines.push({ kind: 'dim', text: `${input.graderId}@${input.graderVersion} · ${input.tagline}` });

  // The server grades the repository's default branch head, not the working
  // tree. Saying so is the difference between a grade and a misleading one.
  if (input.gradedSha === null)
    lines.push({
      kind: 'dim',
      text: `  This grade does not record which commit it read.`,
    });
  else if (input.gradedSha !== input.requestedSha)
    lines.push({
      kind: 'dim',
      text: `  Graded ${short(input.gradedSha)}, not the commit you are on (${short(input.requestedSha)}).`,
    });

  // The caveat belongs to the grader, not to fieldnote, and it only exists
  // because the grader is not purely deterministic. Printing it above the card
  // means nobody reads the number before they read how it was reached.
  if (input.mode !== 'deterministic') lines.push({ kind: 'dim', text: input.disclaimer });
  lines.push({ kind: 'blank', text: '' });

  if (input.score === null || input.presentation === null) {
    lines.push({ kind: 'head', text: 'No score — the evidence was incomplete.' });
    if (input.incompleteReason) lines.push({ kind: 'dim', text: input.incompleteReason });
  } else {
    lines.push({
      kind: 'card',
      text: `${input.score}/100 · ${input.presentation.label} · ${input.presentation.finish}`,
    });
  }
  lines.push({ kind: 'blank', text: '' });

  for (const check of input.checks) {
    const points = `${check.points}/${check.maxPoints}`;
    const trailer = check.paths[0] ?? check.explanation;
    lines.push({ kind: kindOf(check), text: `${title(check)}  ${points}  ${trailer}` });
  }

  if (input.nextTier) {
    lines.push({ kind: 'blank', text: '' });
    lines.push({
      kind: 'head',
      text: `Next: ${input.nextTier.targetFinish} at ${input.nextTier.targetScore}`,
    });
    for (const move of input.nextTier.moves)
      lines.push({ kind: 'dim', text: `  ${move.title}  +${move.points}` });
  }

  lines.push({ kind: 'blank', text: '' });
  lines.push({ kind: 'url', text: input.url });
  return lines;
}
```
